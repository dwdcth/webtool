# Heynote 使用说明（webtool 内置版）

## 基本操作

| 操作 | 快捷键 |
|---|---|
| 新建块 | `Ctrl+Enter` |
| 删除当前块 | `Ctrl+Shift+D` |
| 切换块语言 | `Ctrl+L`（或点块首语言选择器） |
| 块内全选 | `Ctrl+A`（再按一次全文档） |
| 移动块到其他缓冲区 | `Ctrl+S` |
| 搜索 | `Ctrl+F`，跨缓冲区库搜索 `Ctrl+P` |
| 右键菜单 | 编辑器/标签页/缓冲区树/状态栏 各有专属菜单 |

## 块语言与自动检测

每个块独立设置语言（json/math/markdown/…），决定语法高亮、自动格式化和
**编辑行为**。新建块默认 `text-a`（自动检测）：

- **ML 检测**：guesslang 模型分析内容后自动切换语言（对英文效果好，中文短句检测慢或不触发）
- **markdown 快速通道**（webtool 增强，确定性规则、立即生效）：
  - **强信号**（任一命中立即切 markdown）：列表（`- `/`* `/`+ `/`1. `）、
    标题（`#` 后必须有空格）、围栏代码（```）、水平线、表格（表头+分隔行）
  - **弱信号**（累计 2 个切换）：粗体、链接、图片、引用、行内代码、todo 项
  - 误切换不永久：auto 标志保留，ML 检测后续仍可纠正

## ⚠️ 待办列表的空格问题（最常见坑）

**待办格式必须有空格**：

```
- [ ] 买牛奶      ✓ 有效（短横线 + 空格 + [ ] + 空格）
-[ ] 买牛奶       ✗ 无效（"-"和"[ ]"之间没空格）
-[] 买牛奶        ✗ 无效
```

没空格时：不会渲染勾选框、回车**不会自动续写**下一行待办——因为这不构成
markdown 列表语法（CommonMark 规范要求列表符后有空格）。

**中文输入法用户特别注意**：中/英输入法切换瞬间容易把空格吞掉或漏打，
推荐输入顺序：先敲 `-` 和空格（此时块已自动切成 markdown），再切输入法打 `[ ]`，
或整行打完后检查 "-" 后面有没有空格。

其它列表同理（都要空格）：`- 项目` / `* 项目` / `1. 第一项`。

## 图片

- **粘贴**：截图后直接 `Ctrl+V`（宿主读系统剪贴板，需 wl-clipboard/xclip）
- **拖拽**：图片文件拖进编辑器
- 图片持久化在宿主 SQLite（`plugin-data/heynote.blob.db`），重启不丢

## 数据与备份

全部数据（笔记/图片/标签状态）单文件存储：

```
~/.config/webtool/plugin-data/heynote.blob.db
```

备份 = 关闭应用后拷贝该文件；恢复 = 拷回去。详见 README「插件数据存在哪」。
